1 - About this update

The purpose of this update it to resolve some issues with the in-game server-list features of [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]).

In particular, the preview thumbnails (images) used to show which map is currently in use on each of the servers shown in the [b]FoF[/b] multi-player interface.

Currently, the last official update to thumbnail previews a almost [b]two[/b] ([b]2[/b]) years ago, and only included thumbnail previews for "official" maps.  This results in many servers being shown with the generic "[b]Custom Map[/b]" icon, instead of an actual preview thumbnail of the map they are currently running.

In short, what this update does, is to accomplish this:
[previewimg=39970384;sizeFull,floatLeft;HSB-Thumbnails-BeforeAfter.jpg][/previewimg]

2 - Wait, which "server-list"?

[url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) actually has [b]two[/b] different lists of servers, which are related but not the same.  This can cause some confusion, especially for new players.

These [i][b]two[/b][/i] server-list features are:
[list]
[*] The "[b]Highlighted Server Browser[/b]" (or [b]HSB[/b]). list.
[*] The "[b]Full[/b]" server-list.
[/list]

[u][b]Highlighted Server Browser[/b] (or [b]HSB[/b])[/u]:

[previewimg=39967979;sizeFull,floatLeft;FoF-HSB-Thumbnails-Before-Notated.jpg][/previewimg]
[list]
[*] This is the screen you see when you first enter the game, showing thumbnail preview images of different maps running on available game-servers.  Because of its visual nature (images), this is referred-to as the [b][u]Highlighted[/u] Server Browser[/b] (or [b]HSB[/b]).
[*] This feature is how most [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) players find and connect to servers to play the game.  This is [i]especially[/i] true for those new to the game.
[*] This list is [i]heavily [b]curated[/b] to only include select servers[/i] that are "known-good" so-to-speak.  By default, the behind-the-scenes source for the [b]HSB[/b] server-list is [i]only updateable by the game developer directly[/i].  Unfortunately, the developer has been effectively [i]missing-in-action[/i] for some time.
[*] Unfortunately, [b]FoF[/b] currently only includes preview thumbnails for maps that shipped with the game at the time of its last update - nearly [b]two[/b] ([b]2[/b]) years ago.  So no preview thumbnails are included for any custom maps released by the community - resulting in the generic "[b]Custom Map[/b]" icon being shown instead of an actual map preview.
[*] This update installs map preview thumbnails for [i]a wide-array of [b]community-generated[/b] maps[/i].  Installing this update will replace the generic [b]Custom Map[/b] with an actual preview thumbnail for most community maps.
[/list]

[u][b]Full Server List[/b] ("Find Servers")[/u]:

[previewimg=39967981;sizeFull,floatLeft;FoF-HSB-Thumbnails-FindServers.jpg][/previewimg]
[previewimg=39967985;sizeFull,floatLeft;FoF-HSB-Thumbnails-FullServers.jpg][/previewimg]
[list]
[*] On the initial screen, there is also a [b]Find Servers[/b] option.  This will display a more complete list of current [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) game-servers, but [i]without any map-preview images.[/i]
[*] This feature is how many [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) long-term players find and connect to servers to play the game.  In particular the "[b]Favorites[/b]" tab is used extensively by experienced players.
[*] That list is also entirely [b][i][u]un[/u]-curated[/i][/b], and may contain servers that are too electronically distant from you to be playable, or are otherwise problematic.
[*] This update [i]does [b]not[/b] alter the way that "Full" server list works [b]in any way.[/b][/i]
[*] If you use this feature and like it, please feel free to continue doing-so.  I still recommend you apply the update.  However, if you rarely use the [b]HSB[/b] you may see little benefit.
[/list]

3 - Prerequisites (things you need before updating)

Things you need to [b]do[/b] or [b]know[/b] [i]before[/i] updating:
[list]
[*] You must already have [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) installed.
[*] If you have [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) open, close it.
[*] If you did NOT install [b]FoF[/b] to the default location, you must know [i]exactly[/i] where you installed it.  The default location (on Windows) is typically:
[code]C:\Program Files (x86)\Steam\steamapps\common\Fistful of Frags[/code]
[*] For example, you might have installed it to a different Steam "Library" on a different hard-drive, resulting in it being installed somewhere such as:
[code]D:\SteamLibrary\steamapps\common\Fistful of Frags[/code]
[/list]
[b][u]NOTE[/u]:[/b] You [i]may[/i] need to be an "Administrator" on your computer to be able to install software.

5 - How to install the update (using the installer)

[b][u]NOTE[/u]:[/b] An automated installer program is [i]only available for [b]Windows[/b][/i].  For [b]Linux[/b] desktop installations, please see notes further in this guide regarding [i][b]manual[/b] installation[/i].

To start the installer program ([b]FoF-Community-Map-Thumbnails-Update.exe[/b]), just double-click on it - in whatever Windows folder you downloaded it to from your web-browser.  Typically, this defaults to your "[b]Downloads[/b]" folder.

6 - Potential Windows warning

When to try to start the update installer program, Windows may warn that you are trying to run an "[b]unrecognized program[/b]" or "[b]unrecognized app[/b]", as shown below:
[previewimg=39968169;sizeFull,floatLeft;HSB-Thumbnails-Update-Warning-1-Notated.jpg][/previewimg]

If so, you will need to click the "[b]More info[/b]" option, to display the "[b]Run anyway[/b]" button to proceed, as shown below:
[previewimg=39968168;sizeFull,floatLeft;HSB-Thumbnails-Update-Warning-2-Notated.jpg][/previewimg]

7 - Update installation prompts

Once you start the installer program, it will prompt you to select a language.  This is the language the installer program itself will use, and has no bearing or effect on your existing [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) installation.  Select the language you would like, and/or click the [b]Next[/b] button to continue.

[previewimg=39968361;sizeFull,floatLeft;HSB-Thumbnails-Update-Install-1-Notated.jpg][/previewimg]

[hr][/hr]
On the next screen, you have to opportunity to select where your [i][u]existing[/u][/i] [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) is located.  If you have installed to some alternative location (such as a Steam "Library" setup on a secondary drive), use the [b]Browse[/b] button to select the "Fistful of Frags" folder.  Click [b]Next[/b] to continue.

[previewimg=39968360;sizeFull,floatLeft;HSB-Thumbnails-Update-Install-2-Notated.jpg][/previewimg]

[hr][/hr]
If you forgot to exit [b]FoF[/b] (or have any other video-game currently running that happens to be based on the same "Source" game-engine) an error will be displayed - giving you an opportunity to switch back to that game and exit it, before continuing with the update installation.

[previewimg=39968358;sizeFull,floatLeft;HSB-Thumbnails-Update-Install-4-Notated.jpg][/previewimg]

[hr][/hr]
If a valid [i][u]existing[/u][/i] [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) installation is [i]NOT detected[/i] at the location you select, [i]an error will be displayed, and the installation of the update will be [b]cancelled[/b].[/i]  Otherwise, the next screen shown will display the location where the installer is about to apply the update to.  Click [b]Next[/b] to continue.

[previewimg=39968386;sizeFull,floatLeft;HSB-Thumbnails-Update-Install-5-Notated.jpg][/previewimg]

[hr][/hr]
After the update installation completes, a screen will be displayed indicating so.  You may click the [b]Finish[/b] to close the installer.

[previewimg=39968357;sizeFull,floatLeft;HSB-Thumbnails-Update-Install-6-Notated.jpg][/previewimg]

8 - How to use the update

Once the update is successfully installed (either using the installer program or manually), just use [url=https://store.steampowered.com/app/265630/]Fistful of Frags[/url] ([b]FoF[/b]) like normal.  The only difference you should see less of the generic "[b]Custom Map[/b]" icon in the preview thumbnails shown in the [b]Highlighted Server Browser[/b] ([b]HSB[/b]) area of the screen.

For example, you may notice some map thumbnail previews that previously were not displayed:
[previewimg=39968500;sizeFull,floatLeft;FoF-HSB-Thumbnails-After-Notated.jpg][/previewimg]

Of course, exactly which servers you see listed [i]will vary greatly[/i] based on your location / region, communication rates (pings) to various servers, whether or not a server is full, etc.

Also, you can still play on servers that do not show-up in the [b]HSB[/b] at all - by [i]finding them in the [b]"Full" server list[/b][/i], and right-click on them to add them to your "Favorites" tab.
